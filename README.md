# 💌 Сайт-листівка (мобільна версія)

Один файл `index.html`: конверт з печаткою → сторінка з фото і плеєром → фотострічка → галерея з 4 фото → лист і серце в кінці.

## Як змінити вміст
Відкрийте `index.html`, знайдіть блок `const CONFIG = { ... }` на початку файлу:
- `name`, `from`: кому сайт і підпис
- тексти підписів, листа, фраз на фоні
- фото й відео: покладіть файли в папку `photos/` і впишіть шлях, напр. `"photos/1.jpg"` (відео: `.mp4`/`.mov`/`.webm`)
- музика: `song.src`, напр. `"photos/song.mp3"`. Вона вмикається, коли відкривають конверт.

Порожні лапки `""` показують рожеву заглушку «ФОТО N».
